Configuration File

                
Location: config.yaml (same directory as app.py)


                
AWS Configuration

                
aws:
  profile: cluster-manager    # IAM user profile for API operations
  sso_profile: internal       # SSO profile for kubectl access during delete
  regions:
    - eu-central-1            # AWS regions to scan for clusters
    - us-west-2


                
GCP Configuration

                
gcp:
  project: your-project-id
  credentials_file: ~/.config/cluster-manager/gcp-sa.json  # Service account key
  locations:
    - europe-west2            # Regional clusters
    - europe-west3-a          # Zonal clusters


                
Features

                
    
                    
  • Scale Down/Up: Saves node counts before scaling to 0, restores on scale up
    • 
                    
  • Delete: Full cleanup including ECS clusters, load balancers, security groups
    • 
                    
  • Owner Filter: Filter by cluster owner tag/label (default: your username)
    • 
                    
  • CloudFormation: Shows orphaned stacks, allows cleanup
    • 
                    
  • Parallel Operations: Multiple deletions can run simultaneously
    • 
                


                
Required Permissions

                
AWS IAM User:

                
    
                    
  • EKS: Full access (eks:*)
    • 
                    
  • EC2: Describe/Delete for VPCs, Security Groups, ENIs, Load Balancers
    • 
                    
  • CloudFormation: Full access
    • 
                    
  • ECS: List, Describe, Update, Delete for clusters/services/tasks
    • 
                    
  • ELB/ELBv2: Describe and Delete load balancers
    • 
                

                
GCP Service Account:

                
    
                    
  • Kubernetes Engine Admin role
    • 
                


                
Command Line Options

                
python3 app.py [options]
  --debug     Enable debug logging
  --port N    Run on port N (default: 5000)
  --browser   Open in browser instead of native window
